# Xendaria Landing

Landing estática de Xendaria construida con Vite y Tailwind.

## Scripts

```bash
npm run dev
npm run build
npm run preview
```

El contenido principal vive en `index.html`. Los estilos principales están en `src/style.css`, y las interacciones pequeñas, como el menú mobile y el formulario de comercios, están en `src/landing.js`.
